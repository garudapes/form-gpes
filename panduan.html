6

Pemilik Overhaul

Bila Overhaul New Format sudah terpasang, versi terbarunya otomatis masuk antrean Perbarui sekarang. Daftar ID kompetisi di Alat › Cari ID juga otomatis menyesuaikan Overhaul.

Pertanyaan umum
Muncul peringatan Windows / antivirus saat memasang

Wajar untuk aplikasi yang belum terdaftar di Microsoft. Pilih Keep › Keep anyway, lalu More info › Run anyway. Pastikan file diunduh dari link resmi Admin.

Unduhan Google Drive terkena limit

GpesManager otomatis mencoba sumber lain. Bila semua penuh, tunggu beberapa jam lalu coba lagi, atau unduh part yang kurang lewat browser ke folder yang diperiksa. Pemasangan berjalan sendiri begitu semua part lengkap.

Nama file part berubah (mis. “- Copy”, “(1)”)

Umumnya tetap dikenali. Bila tidak, pilih arsipnya sendiri saat diminta, atau ekstrak dulu bila file .rar berada di dalam .rar lain.

Masa aktif habis

Game tetap bisa dimainkan dengan versi terakhir yang terpasang. Update baru terbuka lagi setelah perpanjang (mulai Rp150rb, +300 hari).

Update dari teman / salinan

Tidak bisa dipakai. Update resmi hanya lewat GpesManager di PC yang aktif.
